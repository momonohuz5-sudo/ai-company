# 【初心者向け】BTNからのオープンレイズ完全ガイド｜どのハンドで参加すべき？

## 「どのハンドでレイズしていいか分からない…」と悩んでいませんか？

ポーカーを始めたばかりの頃、最も多くの初心者が直面する悩み。それは**「どのハンドで参加すべきか分からない」**という問題です。

- AAやKKは強いから当然レイズ…でも、K9sは？QToは？
- みんな「タイトに始めろ」と言うけど、具体的にどれくらいタイト？
- ルースすぎてチップを失う…でもタイトすぎてブラインドを払うだけ…

こんな悩みを抱えていませんか？

今日は、ポーカーで最も有利なポジション「**BTN（ボタン）**」からのオープンレイズ戦略について、具体的なハンド選択とその理由を徹底解説します。この記事を読めば、明日からBTNで迷わずにプレイできるようになります！

## なぜBTNが特別なのか？

BTN（ボタン、Buttonの略）は**テーブル上で最も有利なポジション**です。なぜなら：

1. **ポストフロップで常に最後に行動できる**
   - 相手のアクションを見てから判断できる
   - より多くの情報を得られる

2. **ブラインドだけが後ろにいる**
   - プリフロップで対抗してくるプレイヤーが少ない
   - スチールのチャンスが多い

3. **広いレンジでプレイできる**
   - ポジションの優位性により、弱めのハンドも利益を生める

つまり、BTNは**最も攻撃的にプレイすべきポジション**なのです。

## BTNからのオープンレイズ戦略：基本の3原則

### 原則1：約40-50%のハンドでレイズする

BTNからは、配られるハンドの**約40-50%でオープンレイズ**するのが基本戦略です。これは他のポジションと比較すると非常に広いレンジです：

- **UTG（アンダー・ザ・ガン）**: 約15-20%
- **MP（ミドルポジション）**: 約25-30%
- **CO（カットオフ）**: 約35-40%
- **BTN（ボタン）**: 約40-50% ← 最も広い！

### 原則2：レイズサイズは2.5BBが標準

BTNからのオープンレイズサイズは**2.5BB（ビッグブラインド）**が推奨されます。

例：ブラインドが$1/$2の場合 → $5レイズ

なぜ2.5BBなのか？
- 小さすぎるとブラインドがコールしやすくなる
- 大きすぎるとブラフの効率が悪くなる
- 2.5BBは両方のバランスが取れたサイズ

### 原則3：プレミアムハンドは必ずレイズ、マージナルハンドも積極的に

BTNでは**ハンドの強さを3つのカテゴリー**に分けて考えます：

**1. プレミアムハンド（必ずレイズ）**
- AA, KK, QQ, JJ
- AKs, AKo（sはスーテッド=同じスート、oはオフスート=異なるスート）

**2. 強いハンド（積極的にレイズ）**
- TT, 99, 88, 77
- AQs, AQo, AJs, AJo, ATs
- KQs, KJs, KTs

**3. マージナルハンド（BTNだからレイズできる）**
- 66, 55, 44, 33, 22
- A9s, A8s, A7s, A6s, A5s, A4s, A3s, A2s（スーテッドエース）
- KTo, QJo, QTo, JTo
- K9s, Q9s, J9s, T9s, 98s, 87s, 76s（スーテッドコネクター）
- その他のスーテッド・ブロードウェイカード

## 具体例で学ぶ：このハンドはレイズ？フォールド？

### ケース1：K♠9♠が配られた

**答え：レイズ！**

理由：
- スーテッドで2枚のハイカード
- フラッシュとストレートの可能性
- BTNのポジション優位性を活かせる
- ブラインドをスチールできるチャンス

### ケース2：Q♥7♣が配られた

**答え：フォールド**

理由：
- オフスートで弱いキッカー
- ドミネートされやすい（AQやKQに負ける）
- メイドハンドになっても勝率が低い
- BTNでも広げすぎは禁物

### ケース3：5♦5♣が配られた

**答え：レイズ！**

理由：
- ポケットペアはセットバリュー（3カード）が狙える
- 小さいペアでもBTNなら十分にプレイ可能
- ポストフロップでポジションを活かせる
- ブラインドvsブラインドの状況を作りやすい

## 明日から使える実践アドバイス

### アドバイス1：まずは「コアレンジ」から始めよう

いきなり50%のハンドでレイズするのが不安な方は、まず**「コアレンジ」（約35%）**から始めましょう：

- すべてのポケットペア（22+）
- AX以上のエース（A2s+, A5o+）
- KTo+のキング
- QJo+のクイーン
- JTo
- すべてのスーテッドコネクター（98s, 87s, 76s, 65s）

慣れてきたら、K9s, Q9s, J9sなどを追加していきましょう。

### アドバイス2：アクションフォールドなら盗めるチャンス

あなたの前の全員がフォールドした状況（**アクションフォールドされた**）は、ブラインドを盗む絶好のチャンス。この時は少し弱いハンドでも積極的にレイズしましょう。

**成功率の計算：**
- ブラインド合計：1.5BB
- レイズサイズ：2.5BB
- 必要な成功率：2.5 ÷ (2.5 + 1.5) = 62.5%

つまり、**60%以上の確率でブラインドが降りれば利益**になります！

### アドバイス3：相手のタイプを観察する

同じハンドでも、相手によって戦略は変わります：

**タイトな相手（あまりプレイしない）:**
- より広いレンジでレイズOK
- スチール成功率が高い
- 弱いハンドでも利益を生める

**ルースな相手（何でもプレイする）:**
- レンジを少し狭める
- バリュー重視のハンドを選ぶ
- ポストフロップの準備をする

### アドバイス4：フォールドも立派な戦略

BTNだからといって、**無理にルースにする必要はありません**。以下のハンドは自信を持ってフォールドしましょう：

- J8o以下のギャップのあるオフスート
- Q6o以下の弱いクイーン
- K7o以下の弱いキング
- レインボー（全て異なるスート）の弱いハンド

**「フォールドは損失ではなく、利益の保護」**と考えましょう。

## まとめ：BTNレイズのチェックリスト

プレイする前に、この4つを確認しましょう：

✅ **ポジション確認**: 自分はBTNか？
✅ **ハンド評価**: レイズレンジに入っているか？
✅ **前のアクション**: 全員フォールドか？
✅ **相手のタイプ**: タイトかルースか？

この4つをクリアしたら、**自信を持って2.5BBレイズ**しましょう！
