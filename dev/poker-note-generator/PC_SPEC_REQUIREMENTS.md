# ポーカー戦略note自動生成システム - PCスペック要件

## 📊 結論：低スペックPCでも十分動作します

このシステムは**非常に軽量**です。10年前のノートPCでも問題なく動作します。

---

## 💻 推奨スペック

### 最低スペック（これで十分）
| 項目 | 要件 | 理由 |
|------|------|------|
| **CPU** | 2コア以上 | Pythonスクリプト実行のみ |
| **メモリ** | 2GB以上 | Playwright(Chromium)で約500MB使用 |
| **ストレージ** | 500MB | システム + 生成ファイル |
| **OS** | Windows/Mac/Linux | Pythonが動けばOK |
| **ネット** | 常時接続 | Claude API + note投稿 |

### 推奨スペック（快適）
| 項目 | 要件 | 効果 |
|------|------|------|
| **CPU** | 4コア以上 | バッチ生成が少し速くなる |
| **メモリ** | 4GB以上 | 余裕を持って動作 |
| **SSD** | あれば尚良し | ファイル書き込みが速い |

---

## 🔍 各処理のリソース消費

### 1. 記事生成（Claude API呼び出し）
- **CPU使用率**: 5-10%（ほぼ待機時間）
- **メモリ**: 50-100MB
- **時間**: 20-40秒/記事
- **ボトルネック**: ネットワーク速度

**💡 影響**: スペックはほぼ無関係。ネット回線が重要。

---

### 2. レンジチャート生成（matplotlib）
- **CPU使用率**: 20-30%（一瞬）
- **メモリ**: 100-200MB
- **時間**: 1-2秒/画像
- **ボトルネック**: なし

**💡 影響**: 低スペックでも2-3秒で完了。

---

### 3. note自動投稿（Playwright + Chromium）
- **CPU使用率**: 20-40%（ブラウザ起動時）
- **メモリ**: 300-500MB
- **時間**: 30-60秒/投稿
- **ボトルネック**: ネット回線

**💡 影響**: 最もリソースを使うがヘッドレスモードで軽量。

---

### 4. スケジューラー（常駐プロセス）
- **CPU使用率**: 0.1%未満（待機中）
- **メモリ**: 30-50MB
- **時間**: 24時間常駐
- **ボトルネック**: なし

**💡 影響**: バックグラウンドでほぼ無視できる消費量。

## 💰 電気代は？

### 24時間稼働の場合

**低スペックノートPC (15W消費)**
- 電力: 15W × 24h = 0.36kWh/日
- 電気代: 0.36kWh × ¥30/kWh ≈ **¥11/日**
- 月額: **約¥330**

**Raspberry Pi 4 (5W消費)**
- 電力: 5W × 24h = 0.12kWh/日
- 電気代: 0.12kWh × ¥30/kWh ≈ **¥4/日**
- 月額: **約¥120**

**💡 結論**: 電気代も気にならないレベル。

## ⚠️ 唯一の要件：安定したネット回線

**スペックよりも重要なのは「ネット回線の安定性」です**

### 必要な回線速度
- **下り**: 1Mbps以上（Claude API + note投稿）
- **上り**: 512kbps以上（画像アップロード）

### データ通信量（月間）
- Claude API: 約10-50MB/月
- note投稿: 約5-20MB/月
- **合計**: 約50-100MB/月（ほぼゼロ）

**💡 結論**: スマホのテザリングでも余裕で動作。
