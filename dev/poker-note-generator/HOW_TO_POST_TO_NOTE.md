## 🚀 投稿手順（5分）

### 1. noteにログイン

https://note.com にアクセスして、以下のアカウントでログイン:
- **メール**: momonohuz5@gmail.com
- **パスワード**: （あなたのnoteパスワード）

### 2. 新規記事作成

1. 右上の「投稿」ボタンをクリック
2. 「テキスト」を選択

### 3. 記事をコピペ

1. `output/note_ready_to_post.md` を開く
2. 全文をコピー（Ctrl+A → Ctrl+C）
3. noteのエディタに貼り付け（Ctrl+V）

### 4. 画像を追加（オプション）

レンジチャート画像を追加する場合:
- `output/images/sample_tight_range.png` をアップロード
- 記事内の「![BTN オープンレンジチャート](画像URLをここに挿入)」の部分に配置

### 5. 記事設定

#### 基本設定
- **タイトル**: 【初心者必見】BTNからのオープンレイズ完全ガイド｜プリフロップ基礎戦略
- **ハッシュタグ**: #ポーカー #ポーカー戦略 #ポーカー初心者 #プリフロップ #GTO

#### 有料設定（マガジン運営する場合）
1. 「有料エリアを設定」をクリック
2. **価格**: 無料（または500円）
   - 初回は無料がおすすめ（読者獲得）
   - マガジン運営時は500円に設定

#### マガジン追加（将来）
- noteプレミアム会員になると定期購読マガジンを作成可能
- 月額500円のマガジンに記事を追加

### 6. プレビュー確認

1. 右上の「プレビュー」をクリック
2. レイアウトを確認
3. 問題なければ「公開」

### 7. 公開！

「公開する」ボタンをクリックして完了！

## 🎯 次回以降の投稿

このシステムは**毎日1記事を自動生成**できます。

### 自動生成コマンド

```bash

python main.py test-workflow

# 週間5記事生成
python main.py test-batch

# スケジューラー起動（毎日自動投稿）

```

生成された記事は `output/articles/` に保存されます。

## ⚠️ 重要な注意

### noteの利用規約を遵守

- AIで生成した記事であることを明記する必要はありませんが、
- **オリジナルコンテンツ**として価値を提供してください
