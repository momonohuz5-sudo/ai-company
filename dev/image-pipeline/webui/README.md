# WebUI - Streamlit Interface

ComfyUI Image Production PipelineのWebインターフェースです。

## 起動方法

```bash
# 依存関係インストール（初回のみ）
pip install streamlit

# WebUI起動
streamlit run webui/app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 機能

### 🏠 ホーム
- ダッシュボード
- 作品数、ブロック数、接続状態の表示
- クイックスタートガイド

### 📁 作品管理
- 作品一覧表示
- 新規作品作成
- 作品詳細表示

### ✏️ ブロック管理
- プロンプトブロック一覧
- 新規ブロック作成
- Qualityブロックの生成パラメータ設定

### 🎬 シーン計画
- シンプルなシーン計画作成
- ブロック選択UI
- Seed設定

### 🚀 生成実行
- ワークフロー自動構築
- ComfyUIへの一括送信
- Job ID表示

### ✅ 採用管理
- 生成画像のプレビュー
- ワンクリック採用
- 採用済み画像一覧

### 📦 パッケージング
- 連番リネーム
- サンプル分離
- ZIP作成
- パッケージ情報表示
