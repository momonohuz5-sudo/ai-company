# エステ魂 ポチ（リアルタイム集客）自動化

「ポチ早見表」の内容を元にした、6サイト分の「リアルタイム集客(ポチ)」
「集客ワンクリックアピール」を自動クリックする仕組み。Googleカレンダーの
空き状況を見て、ルールに沿ったタイミングだけポチする。

## 構成

- `config.py` — サイト・エリア(ポチユニット)の定義
- `rules.py` — 判定ロジック本体（外部依存なし、テスト可能）
- `calendar_client.py` — Googleカレンダーから空き状況を取得
- `notifier.py` — LINE Messaging APIでの「ポチします」通知
- `site_actions.py` — Playwrightでの管理画面ログイン・クリック
- `state_store.py` — 本日の消化回数・前回ポチ時刻の永続化(JSONファイル)
- `scheduler.py` — エントリポイント。2〜3分おきにcronから起動する想定
- `tests/test_rules.py` — ルールエンジンの単体テスト

## 実装済みのルール

- ポチはポチユニット(エリア)ごとに1日10回まで
- 基本間隔は1時間40分に1回
- 理想タイミングは「ご案内可能時刻の15分前」
- 毎時55分〜次の10分、およびちょうど30分は禁止帯 → 53分/23分にスナップ
- 施術中・直近で案内不可なら禁止
- 他エリアが混雑していて、自エリアが即案内可能なら推奨ポチ
- ポチ可能時間は10:00〜27:30(翌3:30)
- 神田・日本橋：同一ユニット扱い(カレンダー別・同時ポチ・枠共有)
- 田町・八丁堀：カレンダーは共有だが、ポチの実行・枠は別ユニット

## 実装時に置いた仮定（要確認）

- 神田・日本橋の空き判定は「どちらかが空いていれば空き」のOR判定にしている
- 「他エリアが混雑」は、自分以外のポチユニットのうち埋まっているものが
  半数以上かどうかで判定している(具体的な閾値の指定はなかったため)
- カレンダー予定の有無だけで「施術中/空き」を判定している(タイトルや色は見ない)

実際の運用と違う場合は `rules.py` の `decide()` / `scheduler.py` の
`other_areas_busy` 算出部分を調整してください。

## 実行方法(想定)

```bash
pip install -r requirements.txt
playwright install chromium
python scheduler.py
```

2〜3分おきに `python scheduler.py` を呼ぶcronを組む。
