# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 開発部門（Dev）

### 役割
プロダクトの設計・実装・テスト・デプロイを担い、技術的な品質と開発速度を両立させる。

### 主な責務
- 機能要件・非機能要件に基づいたシステム設計
- フロントエンド・バックエンド・インフラの実装
- コードレビューと品質管理
- CI/CD パイプラインの構築・維持
- 技術的負債の管理と継続的なリファクタリング
- 障害対応・パフォーマンス改善

### 開発方針
- シンプルさを優先し、過度な抽象化・先読み設計を避ける
- 変更は小さく・頻繁にリリースする
- 自動テストでデグレを防ぐ
- ドキュメントはコードの近くに置く（README、インラインコメントは「なぜ」のみ）

### ブランチ・レビュー運用
- `main`: 本番相当。直接プッシュ禁止
- `feature/*`: 機能開発ブランチ
- PR は最低1名のレビュー承認後にマージ

### 他部門との関係
- **PM**: タスクを受け取り、完了・ブロックを報告する
- **Research**: 技術選定・PoC の結果を共有・受け取る
- **Marketing**: 公開 API・埋め込みコードの仕様を提供する
